# Portfolio

Un portfolio qui montrera mon expérience mieux que n'importe quel CV.

Et aussi mon terrain de jeu personnel pour pratiquer le CSS et Tailwind. :)

## Technologies utilisées

- React
- TypeScript
- Vite
- Tailwind CSS

## Contenu

- À propos de moi
- Expérience et compétences
- Projets personnels
- Projets universitaires
- Informations de contact
- Liens vers GitHub et LinkedIn

## Développement

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Déploiement

Déployé avec GitHub Pages.
