# Portfolio

A portfolio that will show my experience better than any CV.

Also my personal playground for CSS and Tailwind practice. :)

## Built With

* React
* TypeScript
* Vite
* Tailwind CSS

## What's Inside

* About me
* Experience and skills
* Personal projects
* University projects
* Contact information
* Links to GitHub and LinkedIn

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
